# 🧮 Smart Calculator

[![Deploy with Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/deploy?repository=brainer77798/streamlit-smart-calculator&branch=main&mainModule=app.py)

A modern, responsive calculator built with Python and Streamlit featuring a sleek dark UI/UX (Catppuccin Mocha theme) and real-time computation history.

---

## ✨ Features

- **Standard Operations**: Addition (`+`), Subtraction (`−`), Multiplication (`×`), and Division (`÷`)
- **Advanced Controls**:
  - `+/-`: Toggle positive/negative sign
  - `%`: Direct percentage calculation
  - `⌫`: Character backspace
  - `AC`: Complete display and expression reset
- **History Tracker**: Keeps a log of previous operations and results with a 1-click clear option
- **Zero-Crash Safety**: Safe evaluation engine preventing invalid inputs, recursion errors, and divide-by-zero crashes
- **Responsive UI/UX**: Custom CSS button styling with active transitions and clear display readouts

## 💻 Local Execution

1. **Clone the repository**:
   ```bash
   git clone https://github.com/brainer77798/streamlit-smart-calculator.git
   cd streamlit-smart-calculator
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Streamlit application**:
   ```bash
   streamlit run app.py
   ```
