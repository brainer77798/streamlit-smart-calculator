# 🧮 Smart Calculator

A beautiful, fully-featured calculator built with Python and Streamlit.

## Features

- ✅ Basic operations: Addition, Subtraction, Multiplication, Division
- ✅ Percentage ( % ) and sign toggle ( +/- )
- ✅ Backspace (⌫) for editing
- ✅ Calculation history (last 20 entries)
- ✅ Error handling (division by zero, invalid expressions)
- ✅ Dark theme with Catppuccin Mocha color palette
- ✅ Chained calculations
- ✅ Clean decimal formatting

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy to Streamlit Community Cloud

1. Push this repo to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Click **New app** → select your repo → set `app.py` as the main file
4. Click **Deploy** 🚀
